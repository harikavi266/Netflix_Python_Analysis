📊 Netflix Data Analysis with Pandas & Matplotlib

This project performs comprehensive data cleaning and visualization on a Netflix Movies and TV Shows dataset using Python. The goal is to gain insights into Netflix's content trends, distributions, and metadata using Pandas for processing and Matplotlib (with Seaborn) for plotting.

🔧 Data Cleaning Highlights (50% of project):

Removed duplicates and handled missing values

Standardized text fields (stripping whitespace, converting to lowercase)

Converted date columns to datetime format

Extracted useful features (year, month from date_added; content duration)

Filtered invalid or future year entries

Split multi-value fields (e.g., countries, genres) for better analysis

📈 Visualization Highlights (50% of project):

Yearly and monthly content addition trends

Content type distribution (Movies vs. TV Shows)

Most frequent genres and countries

Ratings distribution across content types

Duration distribution for both movies and TV shows

🧠 Skills Practiced:

Data wrangling with Pandas

Visualization with Matplotlib and Seaborn

Feature engineering

Exploratory Data Analysis (EDA)

Real-world dataset handling
